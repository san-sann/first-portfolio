Site Map

Every page of this demo store, grouped by flow. Each entry names what to try, not just where it leads — so the cart/wishlist state, the checkout flow and the auth chain read as real interactivity, not a static mockup.

Shop Flow

  • Home

    Hero slider, new arrivals, category grid and top brands.

  • Products List

    Switch the New / Recommended tabs and expand a description with Show More.

  • Product Detail

    Pick a size and colour — Add to Cart and the heart icon really write to localStorage.

  • Cart

    Shows the real state carried over from Product Detail — try removing an item.

  • Empty Cart

    Appears automatically once the cart is empty.

    If your cart currently has items, this link bounces you to Cart instead — that's the real redirect guard at work, not a broken link.

  • Checkout

    Billing, shipping and payment forms with live validation.

  • Order Confirmed

    The final step of Checkout — Pay Now clears the cart and lands here for real.

    If your cart currently has items, this link bounces you to Cart instead — Order Confirmed expects the cart to already be cleared.

Account

  • Wishlist

    Real state — heart icons stay in sync across the whole site.

  • Empty Wishlist

    Appears automatically once the wishlist is empty, alongside recently viewed items.

    If your wishlist currently has items, this link bounces you to Wishlist instead — the same redirect guard as Empty Cart.

  • My Orders

    Order history rendered from a small JSON data layer.

  • Order Details

    Status tracker for one real order pulled from My Orders.

  • My Info

    Demo profile and a list of saved addresses.

  • Add Address

    A validated address form.

Auth

  • Sign In

    Also reachable from the person icon in the header.

  • Sign Up

    Registration form for a new account.

  • Reset Password

    Enter any email — it really moves on to Check Email.

  • Check Email

    A deliberate dead end — Resend is a stub with no backend behind it.

  • Verification

    Enter any 4 digits — it really moves on to Create New Password.

  • Create New Password

    Two matching passwords really move on to Sign In — try mismatched ones too, it stays put and shows an error.
